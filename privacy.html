Privacy policy

Personal Mail Reader · Effective October 16, 2026

1. What this is

Personal Mail Reader is a private tool that its owner runs on their own computer, as a local MCP extension for Claude Code (Anthropic) and ChatGPT Desktop/Codex (OpenAI). Only the owner uses it, and only to read the owner's own Gmail accounts. It is not offered to anyone else.

2. Google user data it accesses

With the owner's authorization, it uses the Gmail API with one read-only permission, https://www.googleapis.com/auth/gmail.readonly. This lets it read email messages and their details (sender, recipients, subject, dates, labels), message content and attachments, and list labels. It does not request permission to send, delete or change email, and it does not access any other Google service.

3. How the data is used

Only to carry out the owner's own requests, such as finding a message, summarizing a thread or saving an attachment the owner asks for. It is not used for advertising, profiling or any other purpose.

4. Sharing and transfer

When the owner requests an email task, the email content retrieved for that task is processed by the AI service the owner chooses: Claude/Claude Code, operated by Anthropic, or ChatGPT/Codex, operated by OpenAI. Processing happens only at the owner's request and only to fulfill that task, under the applicable provider's account terms and privacy controls. Model-improvement sharing must remain disabled for this use, including environment sharing where offered; the owner must not submit Google user data through feedback or other optional training-sharing features.

Google user data obtained through this tool is not sold, not used for advertising, not shared with other parties beyond the requested processing by Anthropic or OpenAI described above, and not used to develop, improve or train generalized AI or machine-learning models. No one other than the owner reads it, unless required by law.

5. Storage and security

  • The MCP server runs locally over stdio on the owner's computer, without a public HTTP endpoint or tunnel. It retrieves mail directly from Google over HTTPS; retrieved content supplied to the chosen AI assistant is processed by Anthropic or OpenAI as described above.
  • The authorization tokens Google issues are stored only on the owner's computer, in files readable only by the owner's user account, on an encrypted disk.
  • The tool does not keep its own copy of email. Messages are fetched when the owner asks. Attachments are saved to the owner's computer only on the owner's request.
  • Email content supplied to Claude/Claude Code or ChatGPT/Codex may remain in local or provider-hosted conversation history and may be retained by Anthropic or OpenAI under the applicable account terms and retention controls. Disabling model improvement does not itself disable conversation retention.

6. Retention and deletion

Access lasts until the owner revokes it. Access can be revoked at any time from the Google Account's third-party connections page, which immediately stops the tool from reading mail. The tool's unlink command also deletes the locally stored tokens. The owner can delete local conversation history at any time.

7. Google API Services User Data Policy

Personal Mail Reader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
